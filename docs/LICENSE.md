# 文档和图片的许可

`docs/` 下由本项目撰写的文档，以及本项目自己渲染、绘制的图片（游戏截图、对比图、界面样张、图标），按 [Creative Commons Attribution 4.0 International（CC BY 4.0）](https://creativecommons.org/licenses/by/4.0/) 授权。署名写「mars-realtime-drive contributors」并附仓库链接即可。

不在这个许可范围内的：

- 图片里出现的 NASA / JPL 任务影像和数据：来源和权利状态见仓库根目录的 `THIRD_PARTY.md` §4。
- 车模型贴图上的 NASA 徽标、字标和 JPL 标志：受商标和法规保护，见 `THIRD_PARTY.md` §5。
- 字体、引擎和其他第三方组件：各自的许可见 `THIRD_PARTY.md` §1–3。

代码（GDScript、着色器、C++、Python、Shell）按 MIT 授权，见仓库根目录的 `LICENSE`。
