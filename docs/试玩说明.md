# 火星实景 sol 530 · 试玩说明

在火星杰泽罗撞击坑的三角洲前缘，开着毅力号漫游、拍照、规划火星日的行驶路线。地形、岩石和天空都来自 NASA 的真实数据：轨道相机 HiRISE 和 CTX 的地形，以及毅力号自己的 Navcam 照片。

> 非 NASA / JPL 官方产品。数据来源与许可见 `THIRD_PARTY.md`。

## 需要什么

- Linux x86_64、Windows 10 / 11 x86_64，或 macOS 14+（Apple 芯片）。Linux 和 Windows 要支持 Vulkan 的独立显卡和驱动（Godot 4 的 Forward+ 渲染器）。
- 显存 8 GB。按中端独立显卡、2560×1440 调的；显存小的机器请用「性能」或「低」画质。
- 磁盘约 5 GB（程序和数据解压后）。

## 下载什么

两样都要：

1. **程序包**：按系统选一个。
   - Linux：`…-linux-compat-x86_64.tar.zst` 或 `….AppImage`（二选一）
   - Windows：`…-windows-x86_64.zip`
   - macOS：`…-macos-arm64.zip`
2. **数据包**：`mars-realtime-drive-data-<数据版本>-1of3.zip`、`-2of3.zip`、`-3of3.zip`，**每一卷都要**，三个系统用同一份。每卷单独解压，都得到 `data` 文件夹，解到同一个地方就合在一起了。

程序更新时数据包不一定变：数据版本号没变，就不用重新下。程序打开时会检查数据版本和文件是否齐全，不对会在屏幕上告诉你缺什么、该解压到哪个文件夹。

## 怎么装

下面的命令都在放着下载文件的文件夹里执行。

**Linux · tar.zst**

```sh
tar --zstd -xf mars-realtime-drive-<版本>-linux-compat-x86_64.tar.zst
cd mars-realtime-drive-<版本>-linux-compat
for f in ../mars-realtime-drive-data-*.zip; do unzip -oq "$f"; done      # 得到 data/，和可执行文件并排
./mars-realtime-drive.x86_64
```

**Linux · AppImage**

```sh
chmod +x mars-realtime-drive-<版本>-linux-compat-x86_64.AppImage
for f in mars-realtime-drive-data-*.zip; do unzip -oq "$f"; done          # 得到 data/，和 AppImage 文件并排
./mars-realtime-drive-<版本>-linux-compat-x86_64.AppImage
```

`data` 要放在 AppImage 文件所在的文件夹里（不是 AppImage 里面）。

**Windows**（PowerShell）

```powershell
Expand-Archive mars-realtime-drive-<版本>-windows-x86_64.zip -DestinationPath .
cd mars-realtime-drive-<版本>-windows
Get-ChildItem ..\mars-realtime-drive-data-*.zip | ForEach-Object { Expand-Archive -LiteralPath $_.FullName -DestinationPath . -Force }
.\mars-realtime-drive.exe
```

得到 `mars-realtime-drive.exe` 旁边的 `data` 文件夹。没有代码签名，SmartScreen 会拦：「更多信息 → 仍要运行」。

**macOS**（终端；不要双击数据包，访达会把每卷解成 `data`、`data 2`……）

```sh
ditto -xk mars-realtime-drive-<版本>-macos-arm64.zip .
cd mars-realtime-drive-<版本>-macos
for f in ../mars-realtime-drive-data-*.zip; do ditto -xk "$f" .; done     # 得到 data/，和 mars-realtime-drive.app 并排
xattr -dr com.apple.quarantine mars-realtime-drive.app                      # 没签名没公证：去掉隔离标记，否则被拦
open mars-realtime-drive.app
```

`xattr` 那行不能省：带着隔离标记的 App 会被 macOS 搬到临时位置运行，看不到旁边的 `data`。

**数据放在别处**：命令行加 `-- --数据目录=<data 文件夹>`，或设环境变量 `MARS_DATA=<data 文件夹>`。找 `data` 的顺序：命令行参数 → 环境变量 → 可执行文件旁 → macOS 的 `.app` 内（`Contents/Resources/data`）→ macOS 的 `.app` 旁 → AppImage 旁。

第一次启动要加载大量数据，需要十几秒。

## 怎么玩

- **F1**：全部按键。
- **自由漫游**：开车、看风景。**H** 切换界面档位（精简 → 完整 → 关）。
- **拍照**：**C** 进出拍照模式，界面会全部藏起来；**Tab** 打开相册。
- **兴趣点**：地上和远处悬着的小标是真实的科学目标，例如 Wildcat Ridge、Hogwallow Flats。开近了会弹出导览卡，配有当时 NASA 拍的照片。
- **复刻 NASA 照片**：在相册（**Tab**）的「挑战」页选一张真实的 Navcam 照片，小地图上会出现琥珀色方框，标出当时车停的位置。开过去，按 **C** 进拍照模式对准同一方向，按 **Enter** 交卷。位置、方向、时刻和画面越接近，得分越高，最高三星。
- **火星日规划**：**F2** 进入。每天早上收到下行数据，在规划图上点航点（每段 ≤ 100 m），选驾驶方式，预演一遍再执行，看结束时的报告卡。注意电量和 10:00–15:00 的驾驶时窗。
- **Esc**：第一次放开鼠标，第二次打开暂停菜单。
- **F3** 性能读数和版本号，**F12** 截图。

## 画质

主菜单的「设置」里可以选画质预设（低 / 中 / 性能 / 高）、语言（简体中文 / English）和界面选项。也可以在命令行选画质预设：

```sh
./mars-realtime-drive.x86_64 -- --画质预设=性能     # 低 / 中 / 性能 / 高（默认）
```

也可以写进设置文件 `~/.local/share/godot/app_userdata/火星实景 sol 530/settings.cfg`：

```ini
[args]
v={ "画质预设": "性能" }

[display]
v={ "全屏": "1", "垂直同步": "1" }
```

## 已知问题

- 远处地面的贴图从高处看仍有重复感，新材质还在做。
- 车旁的真实数据区，从某些角度看会有拉长的条纹，因为照片都是从车上的桅杆拍的。
- 退出时终端里会打印「resources still in use」，不影响使用。

## 反馈

遇到问题请带上 **F3** 里显示的版本号，以及终端里的输出。
