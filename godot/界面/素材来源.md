# 界面素材来源与许可

界面（`界面.gd`）只用下面这些外部素材；全部在 fedora 上下载到 `界面/素材/`（该目录有 `.gdignore`，Godot 不导入，运行时用 `FontFile.load_dynamic_font` 直接读）。

## 图标（界面 v3「丙」）

`界面/图标/*.svg`：甲套 32 个，原件 `docs/界面/风格样张/图标/甲/`，坐标写在 `docs/界面/风格样张/生成/图标库.py`，全部自己画（不是 Phosphor / Lucide 的路径），没有 NASA 徽标。目录有 `.gdignore`，运行时由 `界面/图标.gd` 栅格化。

## 影像与数据

- 小地图底图直接用场景已有的 `数据/sol0530/albedo_hirise.png`（HiRISE 彩色，±1000 m）与 `albedo_ctx.png`（CTX，±40 km），不另下载。
  - HiRISE：NASA/JPL-Caltech/University of Arizona；CTX：NASA/JPL-Caltech/MSSS。NASA/JPL 影像一般属公有领域，按惯例署名。
- 站点经纬度、高程、半径同 `scripts/Blender/57_实景重建.py`（LAT 18.45864728° N、LON 77.40592495° E、E0 −2523.168 m、R 3396190 m）；τ = 0.67 为当天 Mastcam-Z 测值。
- 屏幕右下署名（v2 仪表版改成英文小字，中文只在帮助层）："Imagery HiRISE NASA/JPL-Caltech/UArizona"（远档 "CTX NASA/JPL-Caltech/MSSS"）、"Data NASA/JPL-Caltech/ASU/MSSS/UArizona/USGS · not an official NASA product"。

## 刻意不用

NASA 徽标（meatball）、NASA 字标（worm）、任务章 / 任务徽记、JPL 标志，以及任何暗示 NASA 认可或官方身份的东西。标题只写 "PERSEVERANCE · JEZERO CRATER"（事实名称），帮助页注明「非 NASA / JPL 官方产品」。

## 风格参照 v2：仪表式 HUD（2026-10-05 用户否掉 v1 的「网页后台」样式后重做）

原则：用仪表表达状态，不列表格；矢量细线直接叠在画面上，靠描边 / 阴影可读，不用卡片底板。

- Orion 玻璃座舱（Honeywell，3 块 8×10 in 显示器、60 多种格式）：PFD 上姿态仪 + 航向、速度用带式（tape）显示，按飞行阶段重配。
  → 顶部航向带、中下小姿态仪、速度弧表。
  - https://www.designnews.com/aerospace/exclusive-a-closer-look-at-nasa-s-orion-glass-cockpit
  - https://www.smithsonianmag.com/air-space-magazine/orions-brain-21227714/
  - https://www.militaryaerospace.com/commercial-aerospace/article/14224299/commercial-aircraft-avionics-leveraged-for-nextgeneration-nasa-spacecraft
- 航天飞机 MEDS 主飞行显示（PFD）：中心是 ADI 姿态球（俯仰 / 横滚 / 航向），四周是速度、迎角、高度、垂直速度带；下半部是加速度计和航道偏差，配阶段相关的字符数据。
  → 姿态仪的地平线 + 俯仰梯 + 上弧横滚刻度与指针、读数只放必要的几位等宽数字。
  - https://ibiblio.org/apollo/Shuttle/Orbiter%20Displays%20Reference%20Guide%20OI-27.pdf
  - https://wiki.flightgear.org/Space_Shuttle_Avionics
  - https://space1.com/Artifacts/Space_Shuttle_Artifacts/Controls___Displays/Space_Shuttle_ADI/space_shuttle_adi.html
- JPL RSVP（Rover Sequencing and Visualization Program）与其中的 HyperDrive：所有火星车 / 着陆器的指令序列都用它做，HyperDrive 用 2D / 3D 动画回看车的预测与遥测状态（行驶、机械臂、成像）。
  → 左下俯视车体 + 六轮（角轮转角、悬架升降）、阿克曼预测弧、原地转箭头。
  - https://robotics.jpl.nasa.gov/what-we-do/flight-projects/mars-science-laboratory/rsvp-msl/
  - https://robotics.jpl.nasa.gov/what-we-do/applications/user-interfaces
  - https://www.techbriefs.com/component/content/article/884-npo-30845
- 颜色约定照航空 / 航天显示惯例：白为常态，琥珀为注意（caution），红为警告（warning）。车身倾角阈值 20° / 30° 是本游戏的设定，不是毅力号的真实参数。
